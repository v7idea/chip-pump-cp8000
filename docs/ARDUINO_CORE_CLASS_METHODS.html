ArduinoCore-avr 參考結論

官方 AVR core 的根目錄分成 cores/arduino、libraries、 variants、boards.txt、platform.txt。 cores/arduino 內包含語言基礎與所有 sketch 都會依賴的 class； libraries 則包含使用時才拉入的周邊或功能庫。

ArduinoCore-avr 位置 代表檔案 / library 對 CP8000 的設計意義
cores/arduino Arduino.h, main.cpp, wiring.c, wiring_digital.c, wiring_analog.c, HardwareSerial.*, Print.*, Stream.*, WString.*, WMath.cpp, Tone.cpp 這些應視為 CP8000 core parity 的基礎，缺口應放入 MVP / TODO 追蹤。
libraries Wire, SPI, EEPROM, SoftwareSerial, HID CP8000 的 Wire、SPI、CP8000BLE、CP8000RF24G 也應維持 optional library，不放進 core 主路徑。
variants pins_arduino.h, board pin map CP8001 / CP8003 / 後續封裝要靠 variant 管 pin alias、UART pins、LED pin，而不是硬寫在 library。

Core / Library 分層原則

參考成熟 Arduino core 的做法，CP8000 SDK 應該讓 core 只負責所有 sketch 都必須有的最小能力。 其他周邊、協定棧、BLE/RF 這類會吃掉 flash/RAM 或 vendor binary lib 的功能，放在 libraries/ 內，由 sketch 需要時透過 #include 才拉進編譯與連結。

放在 Arduino Core 內

每個 sketch 都需要，或 Arduino 語言本身要求存在的基礎層。

Arduino.h main.cpp wiring.c Print Stream base Printable String WMath HardwareSerial pinMode digitalWrite digitalRead analogRead analogWrite delay millis micros tone pulseIn shiftIn shiftOut interrupts

放在 Optional Libraries

只有使用者 include 時才需要，尤其要避免 BLE/RF stack 汙染 Blink 這種基本 sketch。

Wire SPI CP8000BLE CP8000RF24G CP8000Flash CP8000Watchdog CP8000Sleep EEPROM-like Flash SoftwareSerial BLE GATT BLE OTA

介接規則

  • Core 不直接 include BLE/RF vendor headers。
  • 大型 vendor stack 放在獨立 bridge 檔，讓 linker 只在被引用時拉入。
  • 範例程式要清楚對應 library，例如 BLEDeviceName 必須 include CP8000BLE.h。
  • Blink、Serial、GPIO 類範例應保持小 flash / RAM footprint。
  • 參考 AVR core，String、Printable、WMath、pulseIn、shiftIn/shiftOut、interrupt API 要列為 core parity。

建議處理順序

  • Serial RX 已通：SerialEcho 可收到 macOS USB TTL 傳入的 serial_rx_probe 並原樣回傳。
  • BLESerialBridge close-loop 已通：APP 寫入後可收到 {Payload}(BLE)，macOS serial echo 回板子後可再收到 {Payload}(Serial)。
  • BLE connection callback 與 NUS GATT API wrapper 已補；接著做 BLEConnectionStatus / BLEUartEcho 手機實測。
  • 通用任意 UUID GATT builder 仍延後，等固定 NUS API 穩定後再切。
  • 最後整理 Boards Manager package，做 macOS Docker compile、Arduino IDE install、upload 三段測試。
