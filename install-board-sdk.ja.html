CP8000 Board SDK のインストール

CHIP-PUMP CP8000 Boards Manager URL を Arduino IDE 2.x に追加すると、CP801X-Mini の board package、ツールチェーン、uploader をインストールできます。

Boards Manager URL https://github.com/v7idea/chip-pump-cp8000/releases/download/boards-manager/package_chip-pump_cp8000_index.json

Arduino IDE の手順

Preferences を開く

Arduino IDE で File > Preferences を開き、Additional Boards Manager URLs を探します。

URL を貼り付ける

上記の固定 URL を入力欄に貼り付けます。ほかの URL がある場合は、カンマまたは改行で区切ってください。

CP8000 をインストール

Tools > Board > Boards Manager を開き、CP8000 を検索して CHIP-PUMP CP8000 Boards をインストールします。

ボードを選択

Tools > Board から CP801X-Mini を選び、正しい serial port を選択してサンプルをアップロードします。

Windows Boards Manager キャッシュ

Windows 版 Arduino IDE は古い Boards Manager index や一時パッケージを保持することがあり、IDE で古い SDK バージョンだけが表示される場合があります。公開 URL に新しいリリースがあることを確認済みなのに Boards Manager が更新されない場合は、Arduino IDE を閉じてから下記の CP8000 関連キャッシュだけを削除し、IDE を再起動してください。

削除候補のファイル

C:\Users\<USER>\AppData\Local\Arduino15\package_chip-pump_cp8000_index.json
C:\Users\<USER>\AppData\Local\Arduino15\package_chip-pump_cp8000_index.json.sig
C:\Users\<USER>\AppData\Local\Arduino15\staging\packages\chippump-cp8000-*.tar.gz

PowerShell の例

$arduino15 = Join-Path $env:LOCALAPPDATA "Arduino15"
Remove-Item "$arduino15\package_chip-pump_cp8000_index.json" -ErrorAction SilentlyContinue
Remove-Item "$arduino15\package_chip-pump_cp8000_index.json.sig" -ErrorAction SilentlyContinue
Remove-Item "$arduino15\staging\packages\chippump-cp8000-*.tar.gz" -ErrorAction SilentlyContinue

Arduino15 ディレクトリ全体は削除しないでください。ほかのインストール済みボードやパッケージにも影響します。

Uploader の要件

CP8000 uploader には Python 3.9 以降と pyserial が必要です。0.1.1 以降、serial port が必要な uploader コマンドは pyserial の自動インストールを試みます。管理された環境やオフライン環境では、事前に手動インストールしてください。

Windows

py -3 -m pip install pyserial

macOS / Linux

python3 -m pip install pyserial

Arduino CLI インストール

arduino-cli core update-index \
  --additional-urls https://github.com/v7idea/chip-pump-cp8000/releases/download/boards-manager/package_chip-pump_cp8000_index.json

arduino-cli core install chippump:cp8000 \
  --additional-urls https://github.com/v7idea/chip-pump-cp8000/releases/download/boards-manager/package_chip-pump_cp8000_index.json
公開インストール手順では、常に安定版の boards-manager release URL を使用してください。
