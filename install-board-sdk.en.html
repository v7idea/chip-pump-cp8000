Install the CP8000 Board SDK

Add the CHIP-PUMP CP8000 Boards Manager URL to Arduino IDE 2.x to install the CP8001 SOP16 and CP8003 SOP16 board package, toolchain, and uploader.

Boards Manager URL https://github.com/v7idea/chip-pump-cp8000/releases/download/boards-manager/package_chip-pump_cp8000_index.json

Arduino IDE Steps

Open Preferences

In Arduino IDE, choose File > Preferences, then find Additional Boards Manager URLs.

Paste the URL

Paste the stable URL above. If you already have URLs there, separate them with commas or new lines.

Install CP8000

Open Tools > Board > Boards Manager, search for CP8000, and install CHIP-PUMP CP8000 Boards.

Select the Board

Choose CHIP-PUMP CP8001 SOP16 or CP8003 SOP16 from Tools > Board, then select the correct serial port.

Windows Boards Manager Cache

Arduino IDE on Windows may keep an old Boards Manager index or staged package, so the IDE can still show an older SDK version. If the public URL already has a newer release but Boards Manager does not update, close Arduino IDE, clear only the CP8000 cache files below, then reopen the IDE.

Files You May Clear

C:\Users\<USER>\AppData\Local\Arduino15\package_chip-pump_cp8000_index.json
C:\Users\<USER>\AppData\Local\Arduino15\package_chip-pump_cp8000_index.json.sig
C:\Users\<USER>\AppData\Local\Arduino15\staging\packages\chippump-cp8000-*.tar.gz

PowerShell Example

$arduino15 = Join-Path $env:LOCALAPPDATA "Arduino15"
Remove-Item "$arduino15\package_chip-pump_cp8000_index.json" -ErrorAction SilentlyContinue
Remove-Item "$arduino15\package_chip-pump_cp8000_index.json.sig" -ErrorAction SilentlyContinue
Remove-Item "$arduino15\staging\packages\chippump-cp8000-*.tar.gz" -ErrorAction SilentlyContinue

Do not delete the entire Arduino15 directory unless you intentionally want to reset all installed board packages and indexes.

Uploader Requirement

The CP8000 uploader requires Python 3.9 or later and pyserial. Since 0.1.1, uploader commands that need a serial port try to install pyserial automatically; managed or offline environments can install it manually first.

Windows

py -3 -m pip install pyserial

macOS / Linux

python3 -m pip install pyserial

Arduino CLI Install

arduino-cli core update-index \
  --additional-urls https://github.com/v7idea/chip-pump-cp8000/releases/download/boards-manager/package_chip-pump_cp8000_index.json

arduino-cli core install chippump:cp8000 \
  --additional-urls https://github.com/v7idea/chip-pump-cp8000/releases/download/boards-manager/package_chip-pump_cp8000_index.json
Public install instructions should always use the stable boards-manager release URL.
